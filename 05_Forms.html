± Item / SFG Code * Description Quantity * UOM Remarks

Default (set-to count): the quantity you enter becomes the item's physical stock count (includes any reserved units) — equivalent to a physical reconciliation. Tick ±: the quantity is added (positive) or subtracted (negative) from current physical stock.
Type semantics: Opening seeds a starting balance. Damage / Return / Other record a signed delta (tick ±). Correction is the physical count you measured — system computes the delta.
